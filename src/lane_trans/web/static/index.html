操作

画图：点空白处放节点，连续点击会连线；点已有节点可接上或闭合环；点边会在该处插入节点。Esc 或右键结束当前折线。
移动：拖动节点。
删除：点节点或边（画图模式下空闲时右键也可删除）。
拖动空白处平移，滚轮缩放，两个窗口视图同步。

参数

最大环长 (m)环的连通块总长不超过它才处理
连接裕度两端“多余”分数都低于它才判为横插连接线
平行链比例比最短链长出此倍数的不参与平均
